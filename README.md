# SaasReport landing

saasreport.ai, generated by the SaasReport kit (vendored in `vendor/kit`) from the registries of SaasReport/core
(`vendor/core`), the page's own copy (`content/copy.json`) and made-up sample data (`data/sample`). Nothing on the page is
written by hand: see [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

```sh
npm ci
npm run build   # generate, kit widgets build, kit site build, copy public/ -> dist/ (Cloudflare Pages: output directory dist)
npm test        # kit check canon, the generators' freshness, widgets, site, diagrams, build, shell
npm run qa      # needs Chromium: widgets answer clicks and inputs at 390 and 1280, kit widgets qa
npm run qa:visual
```

To change the page, change a source and run `npm run build`: `content/copy.json` for sentences, `data/sample` for the sample
month, `vendor/core` (by syncing SaasReport/core) for facts. Generated files under `content/generated`, `public/brand`
and `dist` are never edited by hand.
